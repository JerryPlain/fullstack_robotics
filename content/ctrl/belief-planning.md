## 问题

机器人不确定自己在哪的时候，怎么选动作？

[检索](#/n/perc/metric-retrieval)给出的是一个信念，也就是一组带权的位置假设：

$$
b_t = \sum_{j=1}^{k} \pi_{t,j}\, \delta_{\mathbf u_{t,j}}
$$

## 做法：最小化期望代价

对候选动作 $a$，先算出它让每个假设移动多少，再算移动之后到目标的**期望**距离：

$$
C_{\text{atlas}}(a) = \mathbb E_{\mathbf u \sim b_t}\Big[ D_{\mathbf s}\big(\mathbf u + \Delta\mathbf u(a),\ \boldsymbol\mu_{L4}\big) \Big]
= \sum_j \pi_{t,j}\, D_{\mathbf s}\big(\mathbf u_{t,j} + \Delta\mathbf u(a),\ \boldsymbol\mu_{L4}\big)
$$

单位是毫米。不用预测未来的图像，然后用 [CEM](#/n/ctrl/cem) 最小化它。

```python
import numpy as np

def atlas_cost(a, hyps, pi, A, dx, mu_L4, s):
    """hyps: (k, 3) 假设的规范坐标；pi: (k,) 权重；A: (3, 3) 运动映射；dx(a): 世界坐标位移"""
    du = A @ dx(a)                                         # 世界位移 -> 规范坐标位移
    d = np.linalg.norm((hyps + du - mu_L4) * s, axis=1)    # 每个假设移动后到目标的 mm 距离
    return pi @ d                                          # 期望
```

## 为什么不对均值规划：一个小算例

一维里，两个等权假设在 $\mu - d$ 和 $\mu + d$（比如 L3 和 L5，目标 L4 在 $\mu$）。

- **对均值规划**：均值就是 $\mu$。代价 $|\Delta|$ 在 $\Delta = 0$ 时为 0，规划器以为「已经到了」，停住不动；
- **对期望规划**：

$$
\tfrac12 |{-d} + \Delta| + \tfrac12 |d + \Delta| = d \quad \text{对所有 } |\Delta| \le d
$$

期望代价一直是 $d$，也就是整整一节。它**不会**误以为已经到了：它知道无论怎么动，平均都还差一节。打破平局的，是检索时的高斯平滑：彼此一致的邻居权重更高，两簇假设就不再等权。另外探头一动，下一帧的图像会变，信念也会跟着重新形成。

这就是论文里那句话的意思：信念分在 L3 和 L5 之间，不会被当成探头已经在 L4。

## 运动映射：动作 → 坐标位移

候选动作在**世界坐标**里让探头移动 $\Delta\mathbf x(a)$（由体表运动模型给出），规划要的是**规范坐标**里的位移。近似成一个线性映射：

$$
\Delta\mathbf u(a) \approx A\,\Delta\mathbf x(a)
$$

$A$ 在训练病人上取平均，相当于把每个病人 $T_n$ 的 Jacobian 近似成同一个常数矩阵。

消融（42 个验证病人）：每个 episode 用一个固定的随机旋转去转候选位移（「打乱 action map」），Dwell30 掉了 18.3 个点（95% CI [−31.0, −5.6]）。这是三个消融里**唯一**在 Holm 校正后仍然显著的（调整后 p = 0.015）。

> [!note] 运动对应把探头带到目标附近；解剖对应（检索库的坐标、度量头）决定它停在哪。

## 和经典方法的关系

- **粒子滤波**：信念也是一组粒子，但这里没有时间上的更新，每一步都从当前这张图重新检索。用里程计合并最近三帧的版本没有显著更好；
- **QMDP 一类近似**：对当前信念求期望代价，但不显式规划「怎么动才能减少不确定性」；
- **主动感知 / 信息收集**：超声医生会主动去找能消除歧义的切面，这个控制器不会。论文的讨论里也把它列成了下一步。
