> [!one] 策略输出的"关节目标位置"其实是一根虚拟弹簧的平衡点。底层 PD 以远高于策略的频率把它变成力矩，Kp/Kd 决定这根弹簧有多硬、有多大阻尼。RL 学的不是"关节应该在哪"，而是"弹簧应该往哪拉"。

## 直觉

想象你用手扶住一扇摆动的门。你并不是"命令门停在某个角度"，而是像一根弹簧加一个阻尼器：门偏离你想要的位置越多，你推得越用力；门动得越快，你越往反方向"刹"。PD 控制（Proportional-Derivative control，比例-微分控制）做的就是这件事：

- **P 项**：偏离目标越远，回复力矩越大，相当于**弹簧**，系数就是刚度（stiffness）；
- **D 项**：速度越大，阻力越大，相当于**阻尼器**（damper），系数就是阻尼（damping）。

在机器人 RL 里，这个视角尤其重要。策略每 20 ms 输出一组 $q^{\mathrm{des}}$，但这**不是**关节真要到达的位置。支撑腿扛着机身重量，关节永远到不了目标，而目标与实际之差乘以 $K_p$，正好就是撑住身体所需的力矩。换句话说，**策略通过"把弹簧平衡点放在哪"来间接指定力矩**；同时，在两次策略更新之间，PD 一直在提供高频的局部反馈。

阻抗控制（impedance control）是同一思想的推广。它不局限于关节空间，可以在任意空间（比如末端的笛卡尔空间）里规定"机器人对外表现得像多硬的弹簧、多大的阻尼"。它规定的是**运动和力之间的关系**，而不是单纯的位置或单纯的力。

## 形式化

### PD 控制律

$$
\tau = K_p(q^{\mathrm{des}} - q) + K_d(\dot{q}^{\mathrm{des}} - \dot{q})
$$

RL 场景通常取 $\dot{q}^{\mathrm{des}} = 0$，于是 $\tau = K_p(q^{\mathrm{des}} - q) - K_d\dot{q}$。注意这时 D 项阻尼的是**绝对速度**，而不是跟踪误差的变化率，所以它会阻碍一切运动，包括你想要的运动，目标变化很快时会带来相位滞后。$K_p$ 的单位是 N·m/rad，$K_d$ 是 N·m·s/rad，两者通常都是对角矩阵（每个关节各自独立）。

### 二阶系统直觉

只看单个关节，忽略重力和关节间耦合。设等效惯量为 $I$，它包括连杆惯量，也包括经减速比 $N$ 反射过来的转子惯量 $N^2 I_{\mathrm{rotor}}$。闭环动力学是：

$$
I\ddot{q} + K_d\dot{q} + K_p q = K_p q^{\mathrm{des}}
$$

这就是标准的质量–弹簧–阻尼系统，其自然频率和阻尼比为：

$$
\omega_n = \sqrt{\frac{K_p}{I}}, \qquad \zeta = \frac{K_d}{2\sqrt{K_p I}}
$$

- $\zeta < 1$ 是欠阻尼（会过冲、振荡）；$\zeta = 1$ 是临界阻尼（不过冲的前提下最快）；$\zeta > 1$ 是过阻尼（慢）。
- 临界阻尼对应 $K_d = 2\sqrt{K_p I}$。$K_p$ 变为 4 倍时，$K_d$ 只需变为 2 倍就能保持 ζ 不变。
- $\omega_n$ 决定响应速度，上升时间大致与 $1/\omega_n$ 成正比。

举个量级例子（假设等效惯量 $I \approx 0.01$ kg·m²，这只是量级上的假设）。$K_p = 20$、$K_d = 0.5$ 时，$\omega_n = \sqrt{2000} \approx 45$ rad/s（约 7 Hz），$\zeta = 0.5 / (2\sqrt{0.2}) \approx 0.56$，略欠阻尼。更重要的一点是：**同一组增益，在摆动相（只带一条小腿）和支撑相（腿上压着机身）面对的等效惯量差别很大，动态也完全不同。**

### 重力补偿与前馈

存在重力负载 $g(q)$ 时（动力学写作 $M\ddot{q} + C\dot{q} + g(q) = \tau$），纯 PD 的平衡点满足 $K_p(q^{\mathrm{des}} - q) = g(q)$，稳态误差为：

$$
e_{\mathrm{ss}} = q^{\mathrm{des}} - q = K_p^{-1} g(q)
$$

比如关节承受 5 N·m 的重力矩、$K_p = 20$ 时，误差是 0.25 rad，约 14°。消除它的办法是加前馈力矩（feedforward torque）：

$$
\tau = \tau_{\mathrm{ff}} + K_p(q^{\mathrm{des}} - q) + K_d(\dot{q}^{\mathrm{des}} - \dot{q})
$$

- 重力补偿（gravity compensation）：$\tau_{\mathrm{ff}} = g(q)$；
- 完整的逆动力学前馈：$\tau_{\mathrm{ff}} = M(q)\ddot{q}^{\mathrm{des}} + C(q, \dot{q})\dot{q}^{\mathrm{des}} + g(q)$，这时 PD 只负责修正模型误差（见 [动力学](#/learn/ctrl/dynamics)）。

RL 策略一般只填 $q^{\mathrm{des}}$，$\tau_{\mathrm{ff}} = 0$。重力和惯性带来的力矩需求，都由策略通过目标偏移"学"进去。

### 阻抗控制

**关节空间阻抗**。上面带前馈的 PD 本质上就是关节空间阻抗控制，$K_p$ 和 $K_d$ 就是你希望关节表现出的刚度和阻尼。两种说法的区别在于意图：PD 视角关心"跟踪误差有多小"，阻抗视角关心"受外力时表现得有多软"。

**任务空间（笛卡尔）阻抗**。目标是让末端（或足端）表现得像一个笛卡尔空间里的弹簧-阻尼器：

$$
F = K_x(x^{\mathrm{des}} - x) + D_x(\dot{x}^{\mathrm{des}} - \dot{x})
$$

再用雅可比转置（Jacobian transpose）把力映射成关节力矩：

$$
\tau = J(q)^\top F + g(q)
$$

$\tau = J^\top F$ 来自虚功原理：$\delta x = J\delta q$，末端力做的虚功是 $F^\top \delta x = F^\top J \delta q = (J^\top F)^\top \delta q$，所以对应的关节力矩就是 $J^\top F$（雅可比见 [运动学](#/learn/ctrl/kinematics)）。这个形式**不需要逆运动学，也不需要求雅可比的逆**，在奇异位形附近也不会数值发散。姿态部分要用合适的姿态误差（如轴角或四元数误差），不能直接对欧拉角做差。

更一般地，目标阻抗是要求误差 $\tilde{x} = x - x^{\mathrm{des}}$ 在外力下满足 $\Lambda_d\ddot{\tilde{x}} + D_x\dot{\tilde{x}} + K_x\tilde{x} = F_{\mathrm{ext}}$。改变表观惯量 $\Lambda_d$ 通常需要力传感，并用到任务空间惯量 $\Lambda(q)$（即 operational space control）；不改惯量时，就退化成上面"刚度 + 阻尼"的形式。冗余机械臂还要在零空间（nullspace）里加姿态项，见 [全身控制](#/learn/ctrl/wbc)。

### 阻抗 vs 导纳

| | 阻抗控制 (impedance) | 导纳控制 (admittance) |
| --- | --- | --- |
| 因果关系 | 测运动 → 输出力 | 测力 → 输出运动 |
| 内环 | 力矩控制 | 位置或速度控制 |
| 硬件前提 | 可反驱（backdrivable）、力矩可控的执行器，或关节力矩传感器 | 力/力矩传感器（常装在腕部）加上精确的位置控制 |
| 擅长 | 渲染低刚度，和硬环境接触时稳定 | 渲染高刚度、高精度，能压住大减速比带来的摩擦 |
| 弱点 | 难以渲染很高的刚度（受执行器带宽和摩擦限制） | 和很硬的环境接触时容易振荡、失稳 |
| 典型例子 | 准直驱（quasi-direct drive）四足、Franka 的关节力矩模式 | 工业臂加腕部 F/T 传感器，做拖动示教、打磨 |

## 方法

### RL 策略 + PD 的标准接口

```python
# legged_gym 风格：sim_dt = 0.005 s (200 Hz)，decimation = 4 → 策略 50 Hz
q_default = ...                  # 默认站姿 [12]
Kp, Kd = 20.0, 0.5               # 量级参考（Unitree 级别四足）
action_scale = 0.25

def policy_step(obs):
    a = policy(obs)                          # 50 Hz，无量纲动作
    q_des = q_default + action_scale * a     # 目标位置 = 默认站姿 + 缩放后的偏移
    for _ in range(decimation):              # 目标在 4 个子步内保持不变（零阶保持）
        q, qd = sim.get_joint_state()
        tau = Kp * (q_des - q) - Kd * qd     # 每个物理子步都重新计算 PD
        tau = clip(tau, -tau_limit, tau_limit)
        sim.apply_torque(tau)
        sim.step(sim_dt)
```

真机上的接口是一样的：上位机以 50 Hz 跑策略，把 $q^{\mathrm{des}}$ 和 Kp、Kd 发给电机驱动器，驱动器在 kHz 级自己闭环（内层电流环往往更快）。**同一个策略，仿真里 PD 是 200 Hz 算的，真机上是 kHz 算的。** 频率越高越接近连续时间 PD，所以只要增益不太硬，两者表现接近；增益越硬，差别越大。

### 为什么输出位置目标，而不是力矩？

1. **频率分离**。策略网络 50 Hz 推理，再加上通信延迟，当作唯一的反馈回路太慢了。PD 在 200 Hz 到 kHz 提供局部的稳定反馈，像"脊髓反射"，策略只需要做"大脑"层面的决策。如果直接输出力矩，要么策略也得跑到几百 Hz 以上，要么两次更新之间的力矩只能开环。
2. **好的动作先验**。$a = 0$ 对应默认站姿，随机初始化的策略至少会"站着抖"；随机力矩则会让机器人瞬间瘫倒，探索效率极低。Peng & van de Panne (2017) 比较了力矩、PD 目标角等动作参数化，发现带局部反馈的 PD 目标在学习速度和鲁棒性上更好。
3. **有界，量纲统一**。动作乘以 action scale 后对应几十度以内的关节偏移，和关节限位天然吻合。
4. **给 sim-to-real 留缓冲**。PD 的局部反馈会自动修正一部分模型误差（质量、摩擦），开环力矩则把这些误差直接暴露出来。

代价是策略的输出被 PD 动态"过滤"了一层：想要的力矩只能通过 $K_p \times$ 位置偏移间接表达，增益和 action scale 也成了要调的超参数。以 $K_p = 20$、action scale 0.25 为例，动作每变化 1 个单位，目标偏移 0.25 rad，相当于多出 5 N·m 的弹簧力矩。也有工作直接输出力矩（通常配合更高的策略频率和更准确的执行器建模），所以 PD 目标并不是唯一解。

### Kp/Kd：一个"柔顺旋钮"

| | 低增益（软） | 高增益（硬） |
| --- | --- | --- |
| 跟踪 | 误差大，策略必须"夸张"地给目标 | 跟踪准 |
| 冲击 | 落地冲击被"弹簧"吸收 | 冲击直接传到结构和减速器 |
| 噪声 | 动作抖动对力矩影响小 | 动作抖动被 Kp 放大成力矩抖动 |
| 稳定性 | 对延迟和离散化宽容 | 对延迟和采样频率敏感，容易高频振荡 |
| sim-to-real | 对接触、执行器模型误差不敏感 | 放大仿真和真机之间的差异 |

对 Unitree 级别（10–15 kg）的四足，典型量级是 $K_p \sim 20$–$40$ N·m/rad、$K_d \sim 0.5$–$1$ N·m·s/rad。这只是量级参考，不同代码库、不同关节会不一样；更重的机器人、更大的关节，增益也相应更高。很多工作还把 Kp/Kd 或电机力矩强度放进 [域随机化](#/learn/loco/dr)，让策略对真实刚度的不确定性更鲁棒。

### 力矩限制与饱和

执行器有峰值力矩，还有**力矩-转速曲线**（torque-speed curve）：转速越高，反电动势越大，剩下的电压余量越小，能输出的力矩就越低。最简单的线性近似是 $\tau_{\max}(\omega) \approx \tau_{\mathrm{stall}}(1 - \omega/\omega_{\mathrm{noload}})$。实际曲线在低速段常有一个由电流限制决定的平台，驱动和制动两个象限也不对称，这里只取最简单的模型。PD 算出的力矩必须先限幅：

$$
\tau_{\mathrm{cmd}} = \operatorname{clip}\big(\tau_{\mathrm{PD}}, -\tau_{\max}(\dot{q}), \tau_{\max}(\dot{q})\big)
$$

饱和时 PD 不再是线性弹簧，误差会累积并导致超调。更要命的是，如果仿真里只有一个常数力矩上限，策略会学着在高速时使用真实电机根本给不出的力矩（见 [执行器](#/learn/hw/actuators)、[电机控制](#/learn/hw/motor-control)）。

## 机器人视角

> [!robot] **Unitree 的电机指令本身就是 PD + 前馈。** 每个关节发五个量 $(q^{\mathrm{des}}, \dot{q}^{\mathrm{des}}, K_p, K_d, \tau_{\mathrm{ff}})$，驱动器内部计算 $\tau = \tau_{\mathrm{ff}} + K_p(q^{\mathrm{des}} - q) + K_d(\dot{q}^{\mathrm{des}} - \dot{q})$，再交给电流环。RL 部署时通常 $\dot{q}^{\mathrm{des}} = 0$、$\tau_{\mathrm{ff}} = 0$，Kp/Kd 与训练配置一致。反过来，设 Kp = Kd = 0、只发 $\tau_{\mathrm{ff}}$，就是纯力矩控制。

> [!robot] **"动作 1 个单位值多少牛米"是一个很好的直觉检查。** 以 $K_p = 20$、action scale 0.25 为例，动作 1.0 对应目标偏移 0.25 rad；如果关节没动，就多出 5 N·m。拿这个数和支撑机身所需的关节力矩、关节峰值力矩比一比，就能知道策略的输出有多少余量，或者需要多"夸张"的动作。改 Kp 时一般要同步改 action scale，否则就等于改了策略输出的力矩尺度。

> [!robot] **执行器的非理想会通过 PD 被放大。** ANYmal 的串联弹性执行器（SEA）动态比理想 PD 复杂得多。Hwangbo et al. (2019) 用真机数据训练了一个执行器网络（actuator network），在仿真里替代理想 PD，显著缩小了 sim-to-real gap。Unitree 这类准直驱电机更接近理想力矩源，许多工作用"理想 PD + 延迟和摩擦建模 + 域随机化"就能完成迁移。详见 [系统辨识](#/learn/sim/sysid)、[Sim-to-Real](#/learn/sim/sim2real)。

## 常见坑

> [!pitfall] **增益太硬**：以为增益大就是跟踪准、就是好。在 RL 里，过硬的增益会把策略输出的每一点噪声都放大成力矩抖动，电机发热、啸叫，落地冲击直接传到减速器。离散时间下，$\omega_n \Delta t$ 太大还可能直接失稳。仿真里接触刚度和执行器模型的误差也会被放大。建议从偏软的增益开始，让策略学会利用柔顺性。

> [!pitfall] **仿真 PD 和驱动器 PD 对不上**：同样写着 Kp=20，可能根本不是一回事。常见差异有：增益是定义在电机侧还是关节侧（减速比为 $N$ 时，$K_p^{\mathrm{joint}} = N^2 K_p^{\mathrm{motor}}$，$K_d$ 同理）；驱动器对速度做了滤波；仿真里是理想力矩，真机有电流环带宽和摩擦；力矩限幅值不同；仿真器内置的隐式 PD（PhysX 的 joint drive、Isaac Lab 的 implicit actuator）与显式计算的 PD 数值行为也不同。部署前在真机上做阶跃响应，和仿真曲线对比一下。

> [!pitfall] **Decimation 和时序对不上**：训练时 sim_dt = 0.005、decimation = 4，目标在 20 ms 内零阶保持。部署时如果策略实际只跑到 40 Hz，或者驱动器对目标做了插值，或者观测到动作之间多了 10–20 ms 通信延迟，策略面对的就是另一个 MDP（见 [MDP](#/learn/rl/mdp)）。对策：真机上严格定时，并测量端到端延迟；仿真里随机化延迟；保持和训练一致的保持或插值方式。

> [!pitfall] **忽略力矩-转速曲线**：仿真里只设一个常数力矩上限，策略会在高速摆腿时用到真实电机给不出的力矩。结果是仿真里能跑 3 m/s，真机上腿"跟不上"、步态崩掉，或者驱动器触发过流、过压保护。对策：在仿真的力矩限幅里加入随转速下降的上限，并检查训练中各关节的 (转速, 力矩) 分布是否落在电机曲线以内。

## 自测

> [!quiz] $K_p = 20$ N·m/rad，没有前馈，某关节站立时要持续输出 4 N·m 撑住机身。稳态时 $q^{\mathrm{des}}$ 和 $q$ 差多少？这对 RL 策略意味着什么？
> 稳态时 $K_p(q^{\mathrm{des}} - q) = 4$，所以差 0.2 rad，约 11.5°。这说明策略输出的目标位置并不是关节实际所在的位置，支撑腿的目标会系统性地"压进"比实际更深的地方。策略学到的是弹簧平衡点，等价于通过 Kp 指定力矩。如果部署时的实际刚度和训练时不同（比如真机等效 Kp 低 20%），同样的目标就会给出不同的力矩，连站姿高度都会变。

> [!quiz] 某关节等效惯量 $I = 0.02$ kg·m²，$K_p = 30$ N·m/rad，临界阻尼需要多大的 $K_d$？如果 $K_p$ 提到 120 呢？
> $K_d = 2\sqrt{K_p I} = 2\sqrt{0.6} \approx 1.55$ N·m·s/rad。$K_p = 120$ 时 $K_d = 2\sqrt{2.4} \approx 3.1$：Kp 变为 4 倍，Kd 只要变为 2 倍。与此同时，$\omega_n$ 从 $\sqrt{1500} \approx 39$ rad/s 升到 $\sqrt{6000} \approx 77$ rad/s，对控制频率和延迟的要求也跟着提高。

> [!quiz] 任务空间阻抗控制用 $\tau = J^\top F$，为什么不需要算 $J^{-1}$？在奇异位形附近会怎样？
> 由虚功原理，末端力 $F$ 对应的关节力矩就是 $J^\top F$，这是一个正向映射，不涉及求逆。奇异位形下 $J$ 降秩，$J^\top F$ 不会发散；只是 $F$ 中落在 $J^\top$ 零空间里的分量对应零关节力矩，这个方向上的力由结构直接承担，控制器在这个方向上既产生不了主动的力，也产生不了运动。数值上它是安全的。对比之下，基于雅可比逆的速度或位置控制在奇异点附近会要求趋于无穷大的关节速度。

> [!quiz] 同一台机械臂，方案 A 用关节力矩控制做阻抗，方案 B 用位置控制器加腕部力传感器做导纳。分别适合什么场景？
> 阻抗（测运动、出力）适合执行器可反驱、或带关节力矩传感的机器人，比如准直驱的腿、Franka。它擅长低刚度、柔顺的接触，碰到硬表面时也稳定。导纳（测力、出运动）适合减速比大、摩擦大、只能做精确位置控制的工业臂，擅长渲染高刚度和高精度。但它碰到很硬的环境时，力→位置→力这个回路的增益很高，容易振荡；而且只能感知传感器之后的接触力，腕部传感器看不到手臂中段的碰撞。

> [!quiz] 把 Kp 从 20 调到 40、action scale 不变，重新训练之前，"动作的含义"发生了哪些变化？要同步调整什么？
> 同样的动作 a 会产生两倍的弹簧力矩（每单位动作从 5 N·m 变成 10 N·m）。跟踪变硬，噪声对力矩的放大也翻倍，$\omega_n$ 提高到 $\sqrt{2}$ 倍。想保持力矩尺度，可以把 action scale 减半；想保持阻尼比，Kd 要乘以 $\sqrt{2}$（0.5 变成约 0.7）。已经训练好的策略不能直接换增益部署，要么重训，要么训练时就在增益随机化范围里覆盖过新值。
