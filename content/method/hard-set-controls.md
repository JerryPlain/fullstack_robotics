## 降采样：既要小，又要有代表性

完整数据太大，评测要先降采样。设计的规则：

1. 目标数量 = min(总数, 视频数 × 类别数 × 系数)；
2. 按 (视频, 真值标签) 分桶，**每个桶至少留 1 个**，保证每个视频、每个类别都在；
3. 剩下的名额按**最大余数法**（Hamilton 方法）按比例分给各桶；
4. 桶内按时间**均匀**取样，不要扎堆在同一段。

## 难例集：失败的前沿

Hard 子集是**一组模型都容易失败**的样本：

- 对每个样本，算一组模型的平均错误：$\text{PanelError}(x) = \text{mean}_m\big(1 - \text{Perf}_\tau(m, x)\big)$，其中 $\text{Perf}_\tau \in [0, 1]$ 按任务定义（Jaccard、完全匹配、IoU 或归一化的有序一致）；
- 在每个数据集内部排序，取最难的；
- 最后 952 个样本（CholecT50 220 个、Cholec80-CVS 96 个、HeiChole 86 个……）。

## 选了失败的样本，就要防回归均值

审稿人指出的问题：如果按「模型失败」挑出难例，再拿类似的模型（加了工具）重测，分数上升可能只是**回归均值**：第一次的失败里有一部分是随机的，第二次自然会好一点。

camera-ready 的回应：

- **匹配对照（Panel B）**：同一个 prompt，只切换工具开 / 关。器械检测提升 +1.4 到 +9.7，动作识别 +4.6 到 +26.2；
- 一个典型例子：InternVL2.5-8B 的定位在主表里**降了 10.6**，在匹配对照下反而**升了 8.1**。不同的对照方式，结论可以反过来；
- **重复运行**：同样的输入跑多次，预测翻转率只有 0.32%，说明结果不是随机波动。

## 统计：按视频做聚类 bootstrap

- 同一个视频里的帧高度相关，**独立单位是视频，不是帧**；
- 按视频重抽样 1,000 次求置信区间；
- 多个比较用 **BH-FDR**（Benjamini–Hochberg）控制错误发现率，q ≤ 0.05：$p$ 值从小到大排，找最大的 $k$ 使 $p_{(k)} \le \frac{k}{m} q$，前 $k$ 个都算显著。比 [Holm](#/n/method/statistics) 宽松，控制的是「显著结果里错的比例」，不是「至少错一个的概率」。

## 防泄漏

检索库里的病例只来自**训练集**的标注，评测时的标签从来不进知识库。

## 怎么验证一个 LLM 裁判

检索质量用 GPT-5 当裁判打相关性。验证方法：

- 两位外科医生标注 50 次检索调用；
- 算专家之间的一致性（线性加权 κ 0.460），再算专家和 LLM 之间的（0.574 / 0.539）；
- **LLM 和每个专家的一致性，不低于专家之间的一致性**，裁判就算可用；
- 相关性分数对 LLM 裁判的 AUROC 0.894，对人类专家 0.817。
